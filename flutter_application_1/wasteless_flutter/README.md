# Wasteless — Flutter UI

A dependency-light Flutter recreation of the supplied Wasteless mobile UI.

## Included screens

- Welcome / splash
- Onboarding
- Explore / offers grid
- Registration
- Login
- Product details
- Cart
- Checkout
- Order confirmation

The navigation is wired so the prototype can be run immediately. It uses only Flutter + Material icons, so there are no image/package dependencies to configure.

## Run

```bash
flutter pub get
flutter run
```

## Notes

This is a visual prototype based on the reference image. Product photos, maps, authentication, payments and backend data are represented with local UI placeholders and should be connected to real services for production.
